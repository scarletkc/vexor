## Python 3.11 required

Vexor 0.31.0 requires Python 3.11 or newer. Python 3.10 reached end of life in
October 2026, and the security fixes in Pillow 13.0.0 and filelock 4.2.1 are
published only for Python 3.11 and later. On Python 3.10, pip continues to
resolve Vexor 0.30.x.

The standalone executables are now built with Python 3.11. They and the locked
development environment use Pillow 13.0.0, filelock 4.2.4, and pypdf 6.21.2;
the `local` extras use fastembed 0.9.1.

`IndexResult.status` is now a `StrEnum`, so `str(result.status)` returns the
value, such as `"stored"`, instead of `"IndexStatus.STORED"`. Comparisons with
strings and `.value` are unchanged.

With the default terminal output, `vexor search` now checks an up-to-date cache
once instead of twice, and after a rebuild it reports indexing followed by
searching.
