## Batch search

`search_many` adds ordered batch queries to the Python module API, `VexorClient`,
in-memory indexes, and collection handles. Batches share corpus preparation and
embed uncached unique queries together. Results are independent, with separate
content budgets for file searches. Collection batches read from one filtered
snapshot. See
[Python batch search](https://github.com/scarletkc/vexor/blob/v0.30.0/docs/api/python.md#batch-search)
and [collection batches](https://github.com/scarletkc/vexor/blob/v0.30.0/docs/api/collections.md#batch-search).

Embedding responses are now validated more strictly: providers must return one
finite, non-empty vector per input. OpenAI-compatible endpoints must identify
each input exactly once with its integer `index`. Previously tolerated malformed
responses now raise errors.

The repository also includes an
[evidence-based retrieval evaluation suite](https://github.com/scarletkc/vexor/blob/v0.30.0/docs/evaluation.md)
that checks whether returned source content contains the annotated answer.
